WMNavigation - friend pack
==========================

How to run
----------
1. Unzip this folder anywhere (Desktop is fine).
2. Double-click "Launch WMNavigation.bat" or WMNavigation.exe.

Quests & map data
-----------------
Quest lists and map layers (extracts, loot, containers, items) are
bundled inside the exe. You do NOT need TarkovQuestie installed, and
there are no fixed install paths to configure.

On every launch the app auto-imports your active quests from Escape
from Tarkov client logs (wherever EFT is installed — Steam libraries,
other drives, BSG launcher path, etc.). Accept quests in-game first
if the list is empty. Use "Import from logs" only if you want a
manual refresh with a popup.

Edition / auto-update
---------------------
The sidebar shows the current edition (vX.Y.Z).
Packaged builds check GitHub shortly after launch and install newer
releases automatically (download + restart) when a release is public.
